MANUAL

Enter the bank to the right of the town square. Open an item clerk, move one item into storage, then visit Mr. Rich to deposit a little gold.

Only one of your characters can be inside the bank at a time. The first packs are open; deeper vaults must be unlocked.

async function visit_bank() { await smart_move("bank"); await bank_deposit(1); var potions = locate_item("hpot0"); if (potions !== -1) await bank_store(potions); } visit_bank().catch(function (error) { show_json(error); });
